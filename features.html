Security features you can actually use.

📱🧩

App sandboxing

Apps run in separate sandboxes that limit what they can access. GrapheneOS strengthens these boundaries and adds exploit-mitigation improvements to help protect the system and your apps.

👤📱👤

Separate user profiles

Create separate spaces for different activities, each with its own apps and data. Profiles are isolated from one another, and you can end a session to stop its apps from running until you sign in again.

🔐

Built-in duress PIN

GrapheneOS lets you configure a duress PIN and password. Entering the configured credential triggers an irreversible wipe of the device, including installed eSIMs. Set up this feature carefully.

📱✅

More control over permissions

Review and manage what apps can access. GrapheneOS adds controls such as network and sensor permissions, helping you limit access when an app doesn’t need it.

🌐🛡️

Hardened web browsing

GrapheneOS includes Vanadium, a hardened Chromium-based browser and WebView designed to provide additional security protections while supporting everyday browsing.

📲✨

Your choice of apps

Google apps and services aren’t included by default. If you need them, Google Play can be installed as regular sandboxed apps, without special operating-system privileges.

The operating system

Meet GrapheneOS

GrapheneOS is an open-source mobile operating system based on Android, with a focus on privacy and security. Unbound Devices phones use GrapheneOS; Unbound Devices is not affiliated with the GrapheneOS project.
